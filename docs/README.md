## 발표 자료 보는 방법

발표에는 웹 슬라이드 버전을 사용합니다: <https://claude.ai/artifact/WUimdrsFjSxwH6Cxoafmza> (비공개 링크이므로 다른 사람에게 보여 주려면 페이지의 Share 메뉴에서 공유해야 합니다).

`A2A_발표자료.md`는 같은 내용의 원고로, [Marp](https://marp.app) 형식의 Markdown입니다.

- VS Code에 "Marp for VS Code" 확장을 설치하고 파일을 열면 슬라이드로 미리 보고, PDF·PPTX로 내보낼 수 있습니다.
- 확장 없이 열면 일반 문서로 읽힙니다. `---`가 슬라이드 경계이고, HTML 주석은 발표자 노트입니다.
